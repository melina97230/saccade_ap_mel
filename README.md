# 🌿 IA Neurovisuelle – Outil d’Évaluation et de Rééducation du TDAH  
### Version Premium – Adaptée aux enfants neuro‑atypiques

Ce projet est un **prototype clinique** destiné à l’évaluation et à la rééducation des **troubles attentionnels**, notamment dans le cadre du **TDAH**.  
Il utilise une **IA adaptative** pour ajuster la difficulté en temps réel selon les performances du patient.

L’application est développée en **Python / Streamlit** et optimisée pour une utilisation par :

- les **orthoptistes**,  
- les **neuropsychologues**,  
- les **professionnels de la vision**,  
- les **enfants neuro‑atypiques** (TDAH, dys, troubles visuo‑attentionnels).

---

## 🌿 Fonctionnalités principales

### 🎮 Mode Patient  
- Entraînement visuel basé sur la détection de cibles.  
- IA adaptative ajustant la difficulté en temps réel.  
- Mesure des biomarqueurs attentionnels :  
  - temps de réaction,  
  - variabilité,  
  - impulsivité,  
  - erreurs d’inhibition.  
- Calcul d’un **Index Neurovisuel global**.

---

### 🎬 Démo Patient  
- Génération automatique d’une séance réaliste.  
- Idéal pour les démonstrations ou le jury.  
- Résultats enregistrés dans le tableau de bord.

---

### 🧪 Mode Test Orthoptiste  
- Test court (10 cibles) pour évaluer rapidement :  
  - l’attention,  
  - la vitesse,  
  - l’inhibition,  
  - la stabilité visuelle.  
- Interface claire et épurée.

---

### 🧠 Tableau de bord Orthoptiste  
- Visualisation de la progression du patient.  
- Graphiques :  
  - Index neurovisuel,  
  - biomarqueurs,  
  - impulsivité,  
  - variabilité.  
- Profil clinique généré automatiquement.  
- Comparaison **IA vs Standard**.

---

## 🌿 Design Premium – Vert apaisant  
L’interface utilise une palette **vert pastel**, scientifiquement adaptée aux enfants neuro‑atypiques :

- réduit la charge cognitive,  
- diminue l’hyperactivation,  
- améliore la stabilité attentionnelle,  
- favorise la régulation émotionnelle.

## 🚀 Déploiement

L’application peut être déployée gratuitement via **Streamlit Cloud** :

1. Créer un dépôt GitHub  
2. Importer `app.py`, `.streamlit/config.toml` et `data/`  
3. Aller sur https://streamlit.io/cloud  
4. Cliquer **New app**  
5. Sélectionner le dépôt  
6. Déployer 🎉

## 🧬 Objectif clinique  
Ce prototype vise à :

- détecter les **instabilités attentionnelles**,  
- mesurer la **variabilité temporelle**,  
- analyser l’**impulsivité**,  
- soutenir la **rééducation visuo‑attentionnelle**,  
- fournir un **outil moderne** aux orthoptistes.
